# 自愈工作站
## AI 研发实习生工程任务

万象硅芯 · 考核任务 v0.1.0

### 你接手的系统

这是一台具备资料浏览、全文检索和 ZIP 归档功能的工作站。初始版本中，它自己的目录、索引和归档运行环境存在故障，真实请求会失败，原有任务也没有完成。维护页面与固定自检仍可使用。

### 你要实现的能力

在已有代码的基础上，为工作站接入 AI 自修复模块。让 AI 自主查看失败信息、使用适用的恢复资料、选择并调用工具，修复系统自身，保留原件与已有任务，最终恢复可用。

恢复后仍需持续监测；再次引入同类故障时，系统应能自动发现并再次恢复。不能仅返回“已修复”，必须通过实际功能核验。

### 从哪里开始

项目通过 Docker Compose 启动。页面、工具、工作进程、后台监测和独立核验已经提供。主要入口为 solution/agent.py 中的 repair(context, tools)。完整边界与接口见 docs/BOUNDARY.md 和 docs/CONTRACTS.md。

模型服务和实现方式由你选择，请使用 Claude 或 Codex 参与开发。不要求从零重建前后端，不包含语音。固定底座和验收规则不得修改。

### 完成与交付

资料能够实际读取与搜索，归档任务能够生成可解包、内容一致的 ZIP，原有资料和任务完整保留，固定自检全部通过。再次引入故障后，AI 能自主完成新一轮恢复，并适应资源名称不同的同类环境。

提交可运行代码、简明配置说明、真实模型参与的完整演示，以及关键 AI 协作和问题处理记录。如实说明未完成与未验证部分，不提交真实凭据。仅有人工修复或确定性脚本回放不代表完成 AI 能力考核。
